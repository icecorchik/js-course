	5.	Корзина на Map. 
	пояснение почему Map лучше объекта для ключей-чисел и зачем WeakMap нужен для кеша данных по DOM-элементам.
		Map лучше обычного объекта, потому что Map сохраняет тип ключа: числовой ключ 1 и строковый ключ "1" - будут разные ключи. У обычного объекта ключ 1 преобразуется в строку "1"
		WeakMap нужен, когда дополнительные данные (например, кеш или счётчик) надо связать с объектом, например DOM-элементом, но не добавлять в сам объект. WeakMap хранит только объектные ключи: если на объект больше нет других ссылок, сборщик мусора может удалить его вместе с записью. У WeakMap нет перебора и size, потому что содержимое может исчезать.			

Контрольные вопросы

1. Что выполнится раньше: return внутри try или код в finally? Почему?
Сначала вычисляется значение return, затем выполняется finally, и только после finally функция фактически возвращает это значение. Поэтому код очистки в finally выполняется даже при return.

2. Почему try..catch не перехватывает синтаксическую ошибку в самом файле скрипта?
Потому что движок сначала разбирает (парсит) весь файл и только потом запускает его. При синтаксической ошибке выполнение не начинается, поэтому сам блок try ещё не выполняется. try..catch ловит ошибки времени выполнения.

3. Зачем создавать собственные классы ошибок вместо new Error(текст)?
Чтобы отличать причины ошибок через instanceof и хранить дополнительные данные: поле формы, ID товара, остаток. Тогда обработчик выбирает правильное действие, а не анализирует текст сообщения.

4. Как читать стек вызовов в err.stack? Что такое раскрутка стека?
Сверху обычно указано место возникновения ошибки, ниже — функции, которые привели к нему. Раскрутка стека — последовательное завершение вызовов после throw, пока не найдётся подходящий catch.

5. Что такое изоморфная обработка ошибок и чем «ошибка как значение» отличается от исключения?
Это способ сделать обработку одинаковой в разных окружениях и для разных видов функций. Исключение выбрасывается и передаёт управление к catch; ошибка как значение возвращается в обычном объекте или массиве, например { ok: false, error }, и проверяется обычным if.

6. Почему в new Date(2026, 8, 1) получается сентябрь? Что хранит объект Date внутри?
Месяц в конструкторе Date нумеруется с нуля: 0 — январь, 8 — сентябрь. Внутри Date хранит количество миллисекунд относительно 1 января 1970 года UTC; методы только показывают эту дату в нужном формате и часовом поясе.

7. Почему (1.005).toFixed(2) равно '1.00' и как правильно округлять деньги?
Дробные числа хранятся в двоичном формате, и 1.005 представляется приближённо как немного меньшее число. Для денег считают в целых копейках: рубли умножают на 100, округляют до целого и хранят это целое значение.

8. Чем свойство-символ отличается от обычного свойства объекта?
Его ключом является уникальное значение Symbol, а не строка. Такое свойство не попадает в Object.keys, обычный for…in и JSON.stringify, но доступно по самому символу или через Object.getOwnPropertySymbols. Это не механизм защиты.

9. Как устроен протокол итерации и что делает yield в генераторе?
Перебираемый объект предоставляет метод [Symbol.iterator](), который возвращает объект с next(). next() выдаёт { value, done }. yield в генераторе отдаёт очередное значение и приостанавливает функцию до следующего next().

10. Почему WeakMap и WeakSet нельзя перебрать и для чего они нужны?
Они хранят объекты слабыми ссылками: если на объект больше нет других ссылок, сборщик мусора может удалить его. Поэтому состав коллекции может меняться непредсказуемо; нет size и перебора. WeakSet подходит для отметок объектов, WeakMap — для кеша и служебных данных объектов.
