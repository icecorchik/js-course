	5.	Корзина на Map. 
	пояснение почему Map лучше объекта для ключей-чисел и зачем WeakMap нужен для кеша данных по DOM-элементам.
		Map лучше обычного объекта, потому что Map сохраняет тип ключа: числовой ключ 1 и строковый ключ "1" - будут разные ключи. У обычного объекта ключ 1 преобразуется в строку "1"
		WeakMap нужен, когда дополнительные данные (например, кеш или счётчик) надо связать с объектом, например DOM-элементом, но не добавлять в сам объект. WeakMap хранит только объектные ключи: если на объект больше нет других ссылок, сборщик мусора может удалить его вместе с записью. У WeakMap нет перебора и size, потому что содержимое может исчезать.
