1. Чем Function Declaration отличается от Function Expression?

Function Declaration — это объявление функции с помощью ключевого слова function и имени.

function greet() {
    console.log('Привет!');
}
greet();



Function Expression — это функция, которая создаётся как выражение и сохраняется в переменной.

const greet = function() {
    console.log('Привет!');
};
greet();

Function Declaration можно вызвать до её объявления, потому что JavaScript заранее обрабатывает её целиком.
Function Expression через const или let до выполнения строки объявления вызвать нельзя.


2. Что получит параметр, если аргумент не передан? Когда срабатывает значение по умолчанию?
Если аргумент не передан, соответствующий параметр получает значение undefined.

Пример:
function showPrice(price, discount = 0) {
    console.log(price, discount);
}

showPrice(1000);


Результат:
1000 0


Параметр discount получил значение по умолчанию — 0.

Значение по умолчанию используется, если аргумент отсутствует или ему явно передано undefined.

Пример:
showPrice(1000, undefined);


Результат также будет 1000 0.

Но если передать null, значение по умолчанию не сработает:
showPrice(1000, null);


Результат:
1000 null


3. Чем вывод значения через console.log отличается от возврата через return?
console.log() выводит информацию в консоль браузера. Он предназначен для просмотра значений и проверки работы программы.

return возвращает результат из функции в место её вызова и завершает выполнение функции.

Пример:
function example() {
    console.log(100);
}
const result = example();
console.log(result);

Результат:
100
undefined

Функция вывела 100, но ничего не вернула.
Теперь другой пример:
function example() {
    return 100;
}
const result = example();
console.log(result);

Результат:
100

Здесь число 100 действительно возвращается и записывается в переменную result.
Вывод: console.log() показывает информацию, а return передаёт результат вызывающему коду.

4. Почему () =>  возвращает undefined?
Потому что фигурные скобки после стрелки JavaScript воспринимает как тело функции, а не как объект.

Пример:
const example = () => {
    name: 'x'
};

console.log(example());


Здесь функция ничего не возвращает, поэтому результат — undefined.

Чтобы вернуть объект, необходимо заключить его в круглые скобки:
const example = () => ({
    name: 'x'
});

console.log(example());


Результат:
{name: 'x'}


Круглые скобки позволяют JavaScript понять, что внутри находится выражение, возвращающее объект.

5. Что такое лексическое окружение и цепочка областей видимости?
Лексическое окружение — это внутреннее хранилище переменных и других идентификаторов, доступных в определённой области кода.

Каждая функция создаёт собственное окружение при вызове.

Пример:
const shopName = 'Магазин';

function showInfo() {
    const category = 'Компьютеры';

    console.log(shopName);
    console.log(category);
}

showInfo();


Внутри функции доступны:
- собственная переменная category;
- внешняя переменная shopName.
Но снаружи функции переменная category недоступна.

Цепочка областей видимости — это последовательность окружений, по которым JavaScript ищет нужную переменную.

Сначала он ищет переменную в текущем окружении. Если не находит, переходит во внешнее и продолжает поиск.

6. Что такое замыкание? Почему переменная count не исчезает после завершения createCounter?
Замыкание — это функция вместе с лексическим окружением, в котором она была создана.

Пример:
function createCounter() {

    let count = 0;

    return function() {
        count++;
        return count;
    };

}

const counter = createCounter();

console.log(counter());
console.log(counter());


Результат:
1
2


При вызове createCounter() создаётся переменная count.

Затем возвращается внутренняя функция, которая использует эту переменную.

Даже после завершения createCounter() внутренняя функция сохраняет доступ к своему окружению.

Поэтому count продолжает существовать и изменяться.

Замыкания позволяют хранить данные, которые недоступны напрямую извне.

7. Зачем нужны внешние скобки в IIFE?
Внешние круглые скобки превращают объявление функции в функциональное выражение.

Пример:
(function() {
    console.log('Запуск');
})();


Первая пара скобок:
(function() {
    // код
})


превращает функцию в выражение.

Последние скобки:
();


немедленно вызывают её.

IIFE позволяет создать отдельную область видимости и скрыть внутренние переменные от внешнего кода.

8. Что такое стек вызовов и почему рекурсия без базового случая вызывает RangeError?
Стек вызовов — это структура, в которой JavaScript хранит информацию о выполняемых функциях и их вызовах.

Каждый новый вызов функции добавляет в стек новую запись.

Когда функция завершается, её запись удаляется.

Рекурсия — это ситуация, когда функция вызывает саму себя.

Пример:
function factorial(n) {

    if (n <= 1) {
        return 1;
    }

    return n * factorial(n - 1);

}

console.log(factorial(5));


Условие:
if (n <= 1) {
    return 1;
}


является базовым случаем. Оно определяет, когда рекурсия должна завершиться.

Если убрать базовый случай, функция будет бесконечно вызывать саму себя.

В результате стек вызовов переполнится, и JavaScript выдаст:
RangeError: Maximum call stack size exceeded


9. Почему функцию, объявленную через function, можно вызвать до объявления, а через const нельзя?
Function Declaration обрабатывается JavaScript до выполнения основных инструкций программы.

Поэтому функция доступна ещё до строки её объявления.

Пример:
greet();

function greet() {
    console.log('Привет!');
}


Этот код работает.

Но при использовании const:
greet();

const greet = () => {
    console.log('Привет!');
};


возникает ReferenceError.

Это связано с временной мёртвой зоной (TDZ).

Переменная greet становится доступной только после выполнения строки её объявления.

10. Почему изменение поля объекта внутри функции видно снаружи, а присваивание параметру нового объекта нет?
Потому что в JavaScript аргументы передаются по значению. Если аргумент является объектом, передаваемое значение представляет собой ссылку на этот объект.

Пример изменения свойства:
function change(item) {
    item.price = 500;
}

const product = {
    price: 100
};

change(product);

console.log(product.price);


Результат:
500


Параметр item и переменная product указывают на один объект.

Поэтому изменение его свойства видно снаружи.

Теперь рассмотрим замену объекта:
function change(item) {
    item = {
        price: 500
    };
}

const product = {
    price: 100
};

change(product);

console.log(product.price);


Результат:
100


Внутри функции параметру item присваивается новая ссылка. Но переменная product продолжает указывать на старый объект.

Вывод: изменение свойства объекта и присваивание параметру нового объекта — разные операции.
