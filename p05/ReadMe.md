Контрольные вопросы

1. Почему new Array(3) и [3] дают разные массивы?
new Array(3) создаёт массив длиной 3 без элементов. [3] создаёт массив с одним элементом — числом 3.




2. Чем поверхностная копия массива отличается от глубокой? Когда это важно?
Поверхностная копия копирует сам массив, но сохраняет ссылки на вложенные объекты. Глубокая копия создаёт независимые копии вложенных объектов. Это важно, когда нужно изменять копию, не затрагивая оригинал.




3. Чем map отличается от forEach и filter?
- map() — создаёт новый массив, преобразуя каждый элемент.
- forEach() — просто выполняет функцию для каждого элемента.
- filter() — создаёт новый массив только из элементов, прошедших проверку.




4. Что произойдёт, если не передать начальное значение в reduce?
Первый элемент массива станет начальным значением аккумулятора. Если массив пустой, возникнет ошибка.





5. Почему [10, 9, 1, 100].sort() сортирует числа неправильно?
Потому что sort() по умолчанию преобразует элементы в строки и сравнивает их посимвольно. Для чисел нужна функция (a, b) => a - b.





6. Назовите три метода, изменяющих массив, и их неизменяющие аналоги.
- sort() — toSorted().
- splice() — toSpliced().
- push() — создание нового массива через [...array, element].




7. Почему строки в JavaScript неизменяемы и как у примитива могут быть методы?
Строки являются неизменяемыми примитивными значениями. При вызове метода JavaScript временно оборачивает строку в объект String (автоупаковка). Методы возвращают новую строку, не изменяя исходную.





8. Что такое XSS и как его предотвратить при выводе данных через innerHTML?
XSS — межсайтовый скриптинг, при котором вредоносный код внедряется на страницу через данные. Для защиты необходимо экранировать HTML-символы или использовать textContent вместо innerHTML, когда HTML-разметка не нужна.





9. Почему test с флагом g может давать разные ответы для одной строки?
Флаг g заставляет регулярное выражение запоминать позицию поиска в lastIndex. Поэтому повторные вызовы test() могут давать разные результаты.





10. Чем жадный квантификатор отличается от ленивого?
Жадный квантификатор захватывает максимально возможное количество символов. Ленивый (*?, +?) захватывает минимально необходимое количество.
