1. Что выведет typeof для класса и почему?
function, потому что класс в JavaScript является специальным синтаксисом над функцией-конструктором.




2. Где хранятся методы класса: в каждом экземпляре или в одном месте? Как это проверить?
Методы хранятся в ClassName.prototype, а не в каждом экземпляре.
Проверка: obj1.method === obj2.method. Результат будет true.




3. Почему метод, сохранённый в переменную, теряет this? Как это исправить?
Потому что this определяется способом вызова функции. При отдельном вызове связь с объектом теряется.
Исправление: использовать bind():
const fn = obj.method.bind(obj);




4. Чем приватное поле #items отличается от обычного свойства _items?
#items действительно приватное и доступно только внутри класса. _items — обычное публичное свойство. Нижнее подчёркивание является только условным обозначением.




5. Почему обращение к приватному полю снаружи класса — синтаксическая ошибка?
Потому что JavaScript проверяет доступность приватных полей ещё при разборе программы, до её выполнения.




6. Чем статический метод отличается от обычного? Приведите пример.
Статический метод принадлежит самому классу, а обычный — экземплярам через прототип.

Пример:
Product.fromJSON(data);

Метод создаёт товар из полученных данных.




7. Почему вычисляемую сумму лучше делать геттером, а не хранить в поле?
Потому что геттер каждый раз вычисляет сумму по актуальной цене и количеству. Поэтому значение не устаревает после изменения данных.




8. Зачем в конструкторе наследника вызывать super() и почему до этого нельзя использовать this?
super() вызывает конструктор родителя. До его вызова объект наследника ещё не инициализирован, поэтому использовать this нельзя.




9. Как движок находит метод при вызове monitor.describe()?
Сначала ищет метод в самом объекте monitor, затем в PhysicalProduct.prototype, после этого в Product.prototype и далее по цепочке прототипов.




10. Почему в CartView состояние нельзя менять напрямую, а только через setState?
Потому что setState создаёт новое состояние и вызывает render(). При прямом изменении данных отрисовка автоматически не происходит, поэтому отображение может устареть.
