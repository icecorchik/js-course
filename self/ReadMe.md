Контрольные вопросы
1. Что такое DOM и чем он отличается от исходного HTML-кода страницы?
DOM — дерево объектов, которое браузер строит из HTML. Исходный HTML — текст разметки, DOM — живые объекты, которые JavaScript может читать и менять.


2. Почему у <ul> с тремя <li> childNodes.length больше трёх?
Потому что между тегами есть пробелы и переносы строк. Они создают текстовые узлы. children считает только элементы, childNodes — все узлы.


3. Чем живая коллекция отличается от статической? Какие методы возвращают какую?
HTMLCollection от getElementsByTagName/getElementsByClassName — живая и отражает изменения DOM. NodeList из querySelectorAll — статический снимок на момент поиска.


4. Чем textContent отличается от innerHTML? Что такое XSS?
textContent вставляет и читает текст. innerHTML разбирает строку как HTML. XSS — внедрение чужой разметки/кода через недоверенные данные; не вставляй такие данные через innerHTML.


5. Чем атрибут href отличается от свойства href?
Атрибут хранит значение из HTML, например #catalog. Свойство href обычно содержит полный адрес, вычисленный браузером.


6. Почему append уже вставленного элемента перемещает его, а не копирует?
DOM-узел может находиться только в одном месте дерева. append переносит существующий объект. Для копии нужен cloneNode(true).


7. Зачем нужен DocumentFragment?
Чтобы собрать несколько узлов вне документа и вставить их за одну операцию. Сам фрагмент после вставки становится пустым.


8. Почему управлять оформлением лучше через classList, чем через style?
Классы хранят оформление в CSS, а JavaScript только переключает состояние. Это удобнее поддерживать и менять темами.


9. Что означает UI = f(state)? Какую проблему решает?
Интерфейс вычисляется из состояния. Счётчик, количество и сумма строятся из одних данных, поэтому меньше риска, что DOM и данные разойдутся.


10. Почему при полной перерисовке теряется фокус и как это решает обновление по ключу? Какая аналогия у этого в React?
Полная перерисовка удаляет старый input и создаёт новый, а фокус остаётся связан со старым. Обновление по ключу сохраняет существующие узлы и меняет только нужное. В React похожую задачу решают key и согласование виртуального DOM.
