1. Чем let отличается от const? Что именно запрещает const?
let позволяет изменять значение переменной после её создания.
const создаёт константу, которую нельзя переназначить после объявления.

2. Почему typeof null возвращает "object"?
typeof null возвращает "object". Это ошибка первой версии языка 1995 года, которую нельзя исправить: на это поведение опирается слишком много существующего кода.

3.	Почему 0.1 + 0.2 !== 0.3 и как правильно хранить деньги?
Компьютер хранит числа в двоичной системе. Дробь 0.1 в двоичной системе бесконечна, как 1/3 = 0.333… в десятичной, поэтому хранится с округлением. При сложении двух округлённых чисел ошибки складываются, и мы видим 0.30000000000000004. Это свойство формата IEEE 754, оно одинаково во всех языках программирования.
Для денег это недопустимо. Стандартное решение: хранить деньги в копейках целыми числами, все расчёты вести в целых, а при выводе делить на 100.
Правильный способ хранения денег: использовать целые числа в минимальных денежных единицах.

4. Какие значения в JavaScript считаются ложными?
В JavaScript существует шесть основных ложных значений (falsy):
1. false — логическое значение «ложь».
2. 0 — ноль.
3. '' — пустая строка.
4. null — отсутствие значения.
5. undefined — значение не задано.
6. NaN — результат некорректной математической операции.

5. Что вернёт выражение '' || 'нет' и выражение '' ?? 'нет'? Почему?
||. Оператор || возвращает первый истинный операнд. Пустая строка является ложным значением, поэтому возвращается 'нет'.
??. Возвращается пустая строка.
Оператор ?? проверяет только null и undefined. Пустая строка к ним не относится.

6. Чем Number('12px') отличается от parseInt('12px')?
Number() пытается преобразовать всю строку в число.
parseInt() считывает число слева направо, пока встречаются допустимые числовые символы.
Number() преобразует строку целиком, а parseInt() извлекает целую числовую часть в начале строки.

7. Почему после const b = a изменение массива b видно в a?
Потому что массивы являются ссылочными типами данных.
При выполнении const b = a создаётся не новый массив, а копируется ссылка на существующий массив.
Таким образом, обе переменные указывают на один объект в памяти.

8. Что будет в switch, если забыть break?
Если в конструкции switch забыть break, выполнение продолжится в следующих ветках, даже если их условия не совпадают.
Это называется проваливанием (fall-through).

9. Чем while отличается от do…while?
while сначала проверяет условие, а затем выполняет код.
do…while сначала выполняет код, а затем проверяет условие.

10. Что показывают панели Scope, Watch и Call Stack в отладчике? (Взято с нейронки для упрощения)

Scope
Показывает доступные переменные и их текущие значения в момент остановки программы.
Например, можно увидеть:
- локальные переменные функции;
- параметры функции;
- глобальные переменные.

Watch
Позволяет самостоятельно добавлять выражения и следить за их значениями во время выполнения программы.

Call Stack
Показывает стек вызовов функций: какие функции были вызваны и в каком порядке программа дошла до текущего места остановки.
С его помощью можно определить, из какой функции и откуда был вызван проблемный участок кода.

Итог:
- Scope — показывает переменные и их значения.
- Watch — отслеживает выбранные выражения.
- Call Stack — показывает последовательность вызовов функций.
